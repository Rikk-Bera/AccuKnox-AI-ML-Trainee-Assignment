## Assignment 1 — Python Programming and Database Operations

### Q1. Retrieve Books from an API and Store Them in SQLite

This task retrieves book information from the Open Library Search API, stores the retrieved data in an SQLite database, and displays the stored records.

**Technologies:** Python, Requests, SQLite

### Q2. Student Scores Analysis

This task retrieves student score data from an API, calculates the average score, and visualizes individual student scores using a bar chart with an average-score reference line.

**Technologies:** Python, Requests, Pandas, Matplotlib

### Q3. Import CSV Data into SQLite

This task reads records from a CSV file, validates the required columns, stores the data in an SQLite database, and displays the stored records. It also handles blank records and duplicate email addresses.

**Technologies:** Python, CSV, SQLite, SQL

## How to Run the Python Programs

Ensure Python is installed on your system. Install the dependencies required by the programs:

```bash

```

Run the programs from the `Assignment-1` directory:

```bash

python Q2_Student_Scores_Analysis.py
python Q3_CSV_to_SQLite.py
```
